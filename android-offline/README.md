# Daftari Whisper Offline Android

هذا غلاف Android مستقل يضم واجهة التطبيق ومكتباتها محليًا داخل APK. يعمل التطبيق عبر أصل HTTPS محلي يقدّمه WebView؛ وتُرسل استجابات الصفحة والمكتبات ترويستي COOP/COEP اللازمتين لـ WebAssembly متعدد الخيوط. لا تُجرى اتصالات إنترنت، ولا يطلب التطبيق إذن `INTERNET`.

## التثبيت والاستخدام دون إنترنت

1. جهّز على الهاتف ملفّي `Dafter-Whisper-Offline.apk` و`ggml-tiny.bin` مسبقًا (مثلًا بالنقل عبر USB أو بطاقة ذاكرة). لا يحتاج الهاتف إلى اتصال شبكة للتثبيت أو التشغيل.
2. من تطبيق **الملفات** افتح APK وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.
3. افتح **دفترِي Whisper Offline** ثم **الإعدادات ← Whisper دون إنترنت (GGML) ← استيراد نموذج .bin**.
4. في منتقي الملفات اختر **ggml-tiny.bin** المخزّن محليًا وانتظر ظهور «النموذج جاهز». هذا هو مسار الاستيراد المدعوم على الهاتف؛ لا حاجة إلى سحب الملف إلى الشاشة.
5. فعّل **استخدام Whisper للتسجيل الصوتي**. عند أول تسجيل وافق على إذن الميكروفون.

التطبيق لا يطلب إذن الإنترنت، ويحظر تحميل الموارد أو التنقل إلى مواقع خارجية. منتقي نموذج Whisper يطلب ملفات محلية فقط. يُضمَّن التطبيق ومشغّل Whisper، لكن **ملف النموذج نفسه غير مضمّن**؛ يجب نقله إلى الهاتف واختياره مرة واحدة. يُحفظ داخل مساحة التطبيق الخاصة، ولا يحتاج تنزيلًا أو اتصالًا بعد الاستيراد. يُنصح بتوفير مساحة خالية لا تقل عن 200 MB وذاكرة كافية للاستدلال.

## بناء APK قابل للتثبيت

المتطلبات: JDK 17+ وAndroid SDK Platform 35. شغّل:

```bash
./android-offline/build-apk.sh
```

سينتج ملف `Dafter-Whisper-Offline.apk` في جذر المستودع، موقّعًا بمفتاح Android debug الافتراضي وقابلًا للتثبيت الجانبي على الهاتف. (أول بناء على الكمبيوتر قد يحتاج تنزيل Gradle ومكوّنات Android؛ هذا لا يفرض اتصالًا على الهاتف). ويمكن بناءه يدويًا من `android-offline/` باستخدام `./gradlew assembleDebug`.

يُنتج GitHub Actions نسخة debug تلقائيًا عند تحديث مشروع Android، ويمكن تنزيلها من **Actions ← Build offline Android APK ← Artifacts**.

## التوافق ونقل البيانات

- Android 5.0 (API 21) أو أحدث، مع WebView حديث يدعم WebAssembly وSharedArrayBuffer؛ حدّث Android System WebView إن كان قديمًا.
- إصدار التوافق 2.19 موقّع بمخططات APK V1/V2/V3 لتوسيع التوافق مع مثبتات وإصدارات Android.
- معرف الحزمة `ai.arena.dafter.offline` مختلف عن APK السابق `ai.arena.dafter`؛ لذلك يمكن تثبيت النسختين جنبًا إلى جنب ولا يتطلب ذلك إزالة القديمة. لكل نسخة قاعدة بيانات مستقلة. لنقل بياناتك، صدّر نسخة احتياطية من التطبيق القديم ثم استعدها داخل الجديد.
- إذن الميكروفون يطلب عند بدء التسجيل، وليس عند التثبيت. اختيار النموذج يستخدم نافذة الملفات النظامية.
- لم يتوفر جهاز Android فعلي في بيئة التطوير لاختبار التثبيت والميكروفون؛ اختبر الأداء على هاتفك، فسرعة التفريغ واستهلاك الذاكرة يعتمدان على الجهاز.
- `assembleRelease` يحتاج مفتاح توقيع خاصًا محفوظًا محليًا في `signing.local.properties`؛ لا ترفع المفتاح أو كلمة مروره إلى Git.
