# دَفتَري — دفتر ديون البقالة الصوتي

تطبيق ويب محلي 100% (Local-first) لإدارة ديون البقالة: تسجيل صوتي بالعربية، سجلات يدوية، كشوف حساب، نسخ احتياطي مشفّر، ويعمل دون إنترنت. **ملف واحد `index.html` (~630KB) + مكتبات مرخّصة تجاريًا في `lib/`** — بلا خادم تطبيق وبلا بناء.

> الإصدار الحالي: `r368-whisper-ggml-import` (يظهر أسفل الإعدادات وفي `window.__BUILD`).
> الاختبارات: **372 فحصًا / 0 فشل عبر 25 ملفًا** (`npm test`).

---

## 1) الشاشات والميزات (كما هي منفَّذة ومُختبَرة)

### الرئيسية
- بطاقات اليوم: «دين اليوم / سداد اليوم / إجمالي الديون» — الضغط عليها يفلتر السجل (دين+اليوم / سداد+اليوم)، وإجمالي الديون يفتح العملاء بفلتر «عليه دين».
- سجل آخر العمليات مع فلترة (النوع/الفترة) ورقائق مطبَّقة، بحث بالاسم أو المنتج بتطبيع عربي.
- زرّا **دين / سداد** أسفل الشاشة في كل التطبيق: **نقرة = يدوي، ضغطة مطوّلة = صوتي** (قاعدة واحدة).

### العملاء (V1 حسب مواصفة الـ28 بندًا)
- بحث «ابحث بالاسم أو الجوال…» — تطبيع عربي («ابو» يجد «أبو») + بحث بآخر أرقام الجوال وبصيغة `+966`.
- فلاتر سريعة `[الكل][عليه دين][متأخر]` + زر «فلترة» بعدّاد شروط ورقائق قابلة للإزالة `[متأخر ×]`.
- ورقة فلترة متقدمة: الحالة (الكل/عليه دين/متأخر/بدون دين)، سقف الدين (قريب/تجاوز)، الترتيب (آخر نشاط/الأعلى دينًا/الأقل دينًا/الاسم)، [مسح] و[عرض N عميل].
- بطاقة ملخص ديناميكية: «عليهم دين N عملاء / إجمالي الديون»، ومع «متأخر»: «المتأخرون / المبلغ المتأخر».
- بطاقة العميل: Avatar بالحروف، الجوال سطر مستقل، «آخر عملية: منذ X / أمس / تاريخ»، **مبالغ موجبة بلا إشارة سالبة**، وتحذيرات نصية لا أيقونات غامضة:
  - `⚠ متأخر 150.00 ر.س منذ 3 أيام` (المبلغ المتأخر فقط، لا الإجمالي)
  - `⚠ بقي 40.00 ر.س على سقف الدين` (عتبة `NEARLIM=10%` من السقف — ثابت موثّق قابل للتغيير)
  - `⛔ تجاوز سقف الدين بـX`
- البطاقة كلها هدف واحد لصفحة العميل؛ ⋮ يفتح 3 بنود فقط: تعديل / مشاركة كشف الحساب / أرشفة.
- الأرشفة بتأكيد يعرض الرصيد («لا يزال عليه: X») مع شرح أن السجل لا يُحذف؛ شاشة «العملاء المؤرشفون» (بحث + استعادة بتأكيد) عبر ⋮ أعلى الشاشة مع «نقل من الدفتر».
- «+ إضافة عميل» بجانب محدد المتجر؛ الحقول: الاسم*، الجوال (اختياري)، سقف الدين (اختياري) فقط؛ **بوابة الاسم المكرر** [فتح العميل / لا، إضافة عميل جديد] دون منع.
- حالات فارغة: «لا يوجد عملاء بعد» + CTA + «نقل من الدفتر»؛ ونتيجة بحث فارغة: «لا يوجد عميل باسم X» + «+ إضافة X».
- تنقّل سفلي 4 خانات متساوية: الرئيسية / العملاء / التقارير / الإعدادات (أُزيل `+` الأوسط و«متصل»).
- أداء: عرض مجزأ 60 + «عرض المزيد» (`ui.cmax`)؛ الافتراضية `الكل`.

### صفحة العميل (حساب العميل)
- بطاقتا المتبقي / إجمالي المسدد.
- **سجل المعاملات** الزمني الكامل (الأحدث أولًا): دين `−`، سداد `+`، مرتجع/تعديل `من ← إلى`، رصيد افتتاحي — بعدّاد أحداث؛ النقر على دين/مرتجع يفتح الفاتورة، وعلى سداد يفتح «تفاصيل السداد» بتوزيعه على الفواتير.
- قسم «الفواتير» بفلاتر (الكل/مفتوح/جزئي/مسدد) وبطاقات فاتورة بحالة ملوّنة وسجل تعديلات مرئي.

### الفاتورة
- الإجمالي/المدفوع/المتبقي، موعد السداد مع شارة تأخر، تذكير واتساب، سجل دفعات مرقّم، **مرتجع** مع سجل تعديلات، ومشاركة/تصدير.

### الصوت (محركان قابلان للتبديل)
- محرك المتصفح (Web Speech)، وVosk اختياري، وWhisper.cpp اختياري دون إنترنت عبر استيراد نموذج GGML من الإعدادات (`WHISPER-SETUP.md`).
- قواعد نطق صارمة: دين/سداد ← اسم ← مبلغ؛ أرقام منطوقة أو مكتوبة؛ **أي مبلغ غير مسموع بوضوح لا يُحفظ أبدًا** — تحذير واضح + تصحيح يدوي قبل الحفظ؛ فشل الصوت لا يكسر التسجيل اليدوي.

### المزيد
- رصيد افتتاحي، حساب شخصي (مصروف/إيداع بلا عملاء)، إرجاع منتجات، تثبيت عميل، صور عملاء.
- كشف حساب: نص/طباعة/PDF/Excel/QR للعميل؛ نقل كامل بين جهازين عبر QR مضغوط.
- جلسة «نقل من الدفتر» الورقي (OCR عبر Tesseract — **يحتاج إنترنت عند أول استخدام** لجلب النماذج؛ موثّق كقيد صريح).
- نسخ احتياطي JSON بإصدار وتوقيع SHA-256 + نسخة أمان تلقائية؛ استعادة ترفض أي عبث بالتوقيع. **Excel تصدير فقط وليس نسخة احتياطية أبدًا.**
- أمان: قفل PIN بمحدد معدل محاولات، بصمة اختيارية، **تشفير التخزين عند القفل** (IndexedDB يخزّن `{__enc}` لا نصًا صريحًا).
- مظهر نهاري/ليلي/تلقائي، عربي/إنجليزي RTL/LTR.

## 2) النموذج المالي (لا float أبدًا)
- كل المبالغ **أعداد صحيحة minor units** (قروش) في كل المسارات؛ العرض عبر `fmt/money`.
- الأرصدة محسوبة من العمليات (مجموع تلقائي) — **لا رصيد يدوي كمصدر حقيقة أبدًا**.
- السداد الزائد يبقى رصيدًا دائنًا للعميل (قرار منتج).
- schemaVersion=2 مع سجل MIGRATIONS (`{to:2}` تحويل ×100 + لقطة `v1raw` + تراجع آمن عند فشل الثوابت). خطة v3 كاملة في `MIGRATION-PLAN.md` (§18–22): UUID، entries[] موحّدة، أنواع صريحة، source، occurredAt/createdAt، AuditEvent — **بلا حذف بيانات وبلا تغيير schema قبل اختباراته**.

## 3) التخزين والعمل دون إنترنت
- localStorage: `dafter_v3` (قاعدة البيانات)، `dafter_v3_sec` (إعدادات القفل، device-local)، `dafter_v3_enc` (حزمة مشفرة)، `v1raw`، safety-backup.
- IndexedDB مخزن `kv` مفتاح `db` — مشفّر عند القفل.
- Service Worker **v5**: الغلاف network-first (لا نسخة قديمة أبدًا)، المكتبات cache-first للعمل دون إنترنت، وترويسات العزل المطلوبة لـ WebAssembly متعدد الخيوط؛ حذف كاشات قديمة تلقائيًا.

## 4) التشغيل محليًا
```bash
python3 serve.py          # منفذ 3000 مع no-store (أو أي خادم ثابت)
# أو: python3 -m http.server 3000
```
بلا أي بناء. الاختبارات:
```bash
npm install               # jsdom
npm test                  # 372 فحصًا
```

## 5) النشر على GitHub + GitHub Pages
1. أنشئ مستودعًا **خاصًا** وارفع هذا المجلد (التفاصيل في رسالة التسليم أو أوامر أدناه).
2. Pages: Settings ← Pages ← Branch `main` / root — التطبيق ملف ثابت فيعمل مباشرة.
> ملاحظة أمان: التطبيق يخزّن بيانات كل مستخدم على جهازه فقط؛ النشر عامًّا لا يعرّض بيانات أحد، لكن يُفضَّل الخاص.

```bash
git init && git add -A && git commit -m "dafter v1"
git branch -M main
git remote add origin https://github.com/USER/dafter.git
git push -u origin main
```

## 7) قرارات موثّقة (لا تُكسَر)
- لا float في المال؛ لا حذف بيانات؛ لا حذف عمليات مالية بصمت (أرشفة فقط).
- الصوت لا يخمّن مبلغًا؛ AI لا يخترع مبالغًا؛ القيود القديمة بلا `src` تُوسم `sourceUnknown:true` في الهجرة.
- توحيد مصطلح «فلترة»؛ «موعد السداد» لا Due date؛ لا Ledger/Vosk في واجهة المستخدم.
- Excel تصدير فقط؛ مزامنة سحابية NOT_IMPLEMENTED (لا يوجد أي مسار سحابي في الكود).
